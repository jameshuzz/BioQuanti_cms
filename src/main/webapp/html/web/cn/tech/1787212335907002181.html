重组蛋白复溶与保存指南

发布时间：2026-08-19　|　点击：

收到冻干蛋白后请先瞬时离心，再按说明书推荐浓度用蒸馏水复溶，轻轻混匀请勿涡旋。复溶后建议分装保存于 -20℃ 以下，避免反复冻融；2-8℃ 可短期存放 2-7 天。
